How to label
  • Tap a photo to make it its set's pick: the one frame you would post. One pick per set.
  • ✂ Split starts a new set at that photo. Merge with previous joins a set to the one above it.
  • A new set is any photo you might post alongside the others as its own photo. The same spot with a framing change (full-length to headshot) is a new set.
  • ⤢ opens a larger view: ← → to move, P to pick, S to split, Esc to close. On a phone, swipe.
  • The chip on each set is why the engine proposed a boundary there. No AI scores or rankings are shown.
  • Progress is saved in this browser. Export checks every set has one pick, then downloads answer_key.json.

Save it in the repo as eval/__SHOOT_PATH__/answer_key.json: drag the downloaded file into VS Code's Explorer, or copy it into a new file there.
